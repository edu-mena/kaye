# Segurança

## Reportar uma vulnerabilidade

Não abras um issue público. Usa **Security → Report a vulnerability** neste repositório no GitHub (reporte privado). Respondemos em até 3 dias úteis.

Inclui:

- o que encontraste e onde (URL, endpoint, ecrã);
- como reproduzir;
- o impacto que imaginas.

Não acedas a dados de outras pessoas, não degrades o serviço e não publiques nada antes de corrigirmos.
