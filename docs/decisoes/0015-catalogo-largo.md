# 0015. Catálogo largo: todas as áreas desde o MVP

5 de novembro de 2026 · Estado: Aceite (substitui a 0009)

## Contexto

- A 0009 dizia que o catálogo crescia uma área de cada vez, a começar pela Saúde, a partir do MVP "Kayé Tech", que era só de tecnologia.
- Hoje a app já tem as 13 áreas do Mercado (`MARKET_AREAS`), cada uma com guias de profissões, cursos e empresas.
- A oferta de valor (ponto 8) assume um catálogo largo: o Kayé orienta jovens de todas as áreas, não só da tecnologia.

## Decisão

- O catálogo cobre todas as áreas do Mercado desde o MVP. O MVP é em Luanda primeiro e é tudo grátis.
- A profundidade de cada área (mais profissões, guias completos, cursos, empregadores) cresce pelo que os utilizadores pedem, e não por uma ordem fixa de áreas.
- As regras de dados da 0009 (fontes públicas, salários só com tabela ou inquérito com fonte, nada de nomes de pessoas) e a forma de acrescentar uma área continuam válidas.

## Consequências

- Há mais dados para manter. A recolha semanal ajuda a mantê-los actualizados.
- A mensagem deixa de ser "Kayé Tech": a app apresenta-se como orientação para todas as áreas.
- Os pedidos dos utilizadores passam a decidir onde se aprofunda primeiro.
